Here's a table listing some common **cryptography tools**:

| **Tool**          | **Description**                                                         | **Usage**                                                   | **Platform**       |
|-------------------|-------------------------------------------------------------------------|-------------------------------------------------------------|--------------------|
| **OpenSSL**       | Used for encryption, decryption, and SSL/TLS certificate generation.     | Encrypt/decrypt files, create certificates.                 | Linux, Windows, macOS |
| **GPG (GnuPG)**   | Open-source tool for encrypting data and creating digital signatures.    | Encrypt messages, create and verify digital signatures.     | Linux, Windows, macOS |
| **John the Ripper** | A tool for cracking password hashes.                                    | Crack password hashes using various algorithms.             | Linux, Windows, macOS |
| **Hashcat**       | A high-speed password cracker using GPU/CPU for hash cracking.          | Crack password hashes faster using GPUs.                   | Linux, Windows, macOS |
| **Steghide**      | Tool for hiding data in image/audio files using encryption.              | Embed or extract data from images/audio files.              | Linux, Windows     |
| **CyberChef**     | Web-based tool for performing various cryptographic operations.         | Encrypt, decrypt, encode, decode, and transform data.       | Web-based          |
| **Cryptsetup**    | Tool for disk encryption using LUKS.                                    | Encrypt disk partitions or volumes.                         | Linux              |
| **VeraCrypt**     | Open-source tool for creating encrypted volumes or full disk encryption. | Encrypt disks or create encrypted containers.               | Linux, Windows, macOS |
| **TrueCrypt**     | Discontinued but still widely used for disk encryption.                  | Encrypt disk partitions or create encrypted volumes.        | Windows, macOS     |
| **Base64**        | Encodes and decodes data in Base64 format.                               | Encode or decode data in Base64.                            | Linux, Windows, macOS |
