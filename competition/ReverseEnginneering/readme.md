
### **Reverse Engineering**  
Focus on understanding how compiled programs work and extracting information.  

#### **1. Tools to Learn**  
- **Ghidra / IDA Pro** (Disassemblers for analyzing binary code)  
- **Radare2 / Cutter** (Open-source reverse engineering tools)  
- **x64dbg / OllyDbg** (Windows debugging tools)  

#### **2. Binary Analysis**  
- **ELF & PE files** (Understand Linux & Windows executables)  
- **Strings Analysis** (`strings` command, binwalk)  
- **Function Analysis** (Identify main functions in assembly)  

#### **3. Common CTF Reverse Challenges**  
- **Finding Hardcoded Keys** (Look for API keys, passwords)  
- **Obfuscation & Anti-debugging** (How malware hides)  
- **Basic Crackmes** (Modify conditions in a program)
